# Refined A-line model — 25 September 2026

The active app asset `assets/models/luvly_aline.glb` now contains the refined gown. Its editable source is `design/dresses/luvly_aline_refined.blend`; construction script is `refine_aline.py`. Original GLB retained as `luvly_aline_original.glb` for rollback; original `.blend` remains unchanged.

Visual reference found through image search: Casablanca Bridal, Style 2575 Lorelai, https://www.casablancabridal.com/collections/luxe-romance/style-2575-lorelai/ . Reference features: sweetheart bodice, folded neckline and pleated A-line skirt. The product page blocked direct retrieval; search-indexed imagery/description supplied the reference. No retailer photograph was downloaded, embedded, redistributed, or used as a texture.

This is an original AI-assisted, photo-informed procedural interpretation, not an exact replica, scan, or automatic photo-to-3D reconstruction. It remains a prototype rather than a photorealistic garment.

Changes: paired bust shaping, shallow diagonal bodice folds, folded neckline, continuous narrow waist seam, varied skirt pleats, short sweep train, and covered back buttons. PBR ivory material is exported with the geometry. Studio floor, lights and camera are excluded from GLB.

The rendered PNG uses Cycles studio lighting; mobile Filament lighting differs, so the app will not look exactly like this studio image. No animation, rigging, dynamic cloth, arm occlusion or fit guarantee has been added. Original metre units and shoulder/hip anchors are retained. Real-phone visual/performance testing remains necessary (approximately 53,000 triangles, under 1 MB GLB).
